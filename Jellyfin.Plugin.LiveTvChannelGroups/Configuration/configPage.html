Live TV Channel Groups

Define named groups with keywords (e.g. Hockey → hockey, nhl, sportsnet). Matching channels are tagged with the group name, and — if "Also sync as Collections" is on — kept in a Collection of the same name so the group is browsable from any Jellyfin client, including third-party apps such as Moonfin.

Note: custom groups cannot add new buttons to Moonfin's (or the web client's) built-in Live TV guide filter rail — that rail only understands Jellyfin's fixed Movies/Series/News/Kids/Sports/Favorites categories. Collections are the part of this plugin that actually shows up as a distinct, named, browsable group today.

Creates/updates a Collection per group containing its matched channels.
